# Docs

O projeto foi reposicionado para um agente autonomo de candidatura.

## Areas principais
- `Profile Brain`: perfil persistido e evidencias profissionais
- `Job Intake`: discovery, score e priorizacao
- `Application Engine`: conectores e execucoes auditaveis
- `Inbox Sync`: eventos de e-mail e reconciliacao de status
- `Dashboard`: painel operacional
